# Abi Precious Jibrin — portfolio

Personal portfolio of Abi Precious Jibrin, Public Health Programme & Systems Specialist. Live at [jibriva.com](https://www.jibriva.com).

## Pages

Home, About, Projects (OneHealth Hub; Nigeria Brucellosis Surveillance Analysis), Experience, Resume (with PDF), Contact, Privacy and Terms.

## Tech

- Next.js 16 (App Router), TypeScript, Tailwind CSS v4
- Content lives in typed files under `content/`; pages under `app/`
- Light and dark themes from CSS variables in `app/globals.css`
- Hosted on Vercel

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm run lint
```
